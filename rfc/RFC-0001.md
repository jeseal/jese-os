# RFC-0001: Formato Oficial de Transacciones

Versión: 1.0
Estado: Activo
Autor: Jesé Alvarado + Claude (Anthropic)
Fecha: 2026-07-03

---

## Propósito

Este documento define el formato oficial para registrar transacciones dentro del sistema SOFP.

El formato debe:

- Capturar el contexto completo de cada decisión financiera.
- Ser fácil de registrar desde el chat.
- Ser legible por humanos y por sistemas automatizados.
- Evolucionar junto con el sistema sin romper registros históricos.

---

## Principio fundamental

En SOFP no se registran transacciones.

Se registran decisiones.

Cada entrada del journal debe responder:

¿Qué ocurrió? ¿Por qué? ¿Para quién? ¿Con qué frecuencia? ¿Qué valor representa? ¿Qué objetivo afecta?

---

## Ubicación de los registros

Los registros de transacciones viven en el journal mensual:

```
journal/
  2026/
    2026-07.md
    2026-08.md
  2027/
    2027-01.md
```

Cada archivo contiene todas las transacciones del mes correspondiente.

---

## Formato de una transacción

Cada transacción se registra como un bloque en el archivo mensual.

### Campos obligatorios

```
- fecha: YYYY-MM-DD
- monto: número en la moneda registrada (CRC o USD)
- moneda: CRC | USD
- descripcion: texto libre, claro y específico
- categoria: ver catálogo de categorías
- tipo: Necesidad | Familia | Personal | Aprendizaje | Inversión | Ocio | Salud
- prioridad: Esencial | Importante | Opcional
- frecuencia: Recurrente | Ocasional | Extraordinario | Único
- flujo: Gasto | Ingreso | Transferencia | Ahorro
```

### Campos opcionales pero recomendados

```
- personas: lista de personas involucradas (ej: esposa, mamá, bebé)
- valores: lista de valores personales que representa (ej: Familia, Salud)
- objetivo: objetivo financiero relacionado (ej: Fondo de emergencia)
- notas: contexto adicional relevante
- etiquetas: palabras clave para búsqueda futura
```

---

## Formato en el archivo markdown

Cada transacción se registra como una sección con este formato:

```markdown
### [YYYY-MM-DD] Descripción breve

| Campo      | Valor                        |
|------------|------------------------------|
| Monto      | ₡XX,XXX / $XXX               |
| Flujo      | Gasto                        |
| Categoría  | Supermercado                 |
| Tipo       | Necesidad                    |
| Prioridad  | Esencial                     |
| Frecuencia | Recurrente                   |
| Personas   | Esposa                       |
| Valores    | Familia, Responsabilidad     |
| Objetivo   | —                            |
| Notas      | Compra semanal del hogar.    |
```

## Reglas de registro

### Regla 1 — Registrar solo lo de Jesé

Si un gasto fue compartido, se registra únicamente la parte correspondiente a Jesé.

Si hubo reembolso posterior, se registra como ingreso separado con referencia a la transacción original.

### Regla 2 — Los gastos extraordinarios se marcan

Todo gasto con frecuencia `Extraordinario` o `Único` debe tener una nota explicando por qué ocurrió.

Estos gastos nunca deben usarse como base para proyecciones futuras.

### Regla 3 — El contexto siempre importa

Un gasto en restaurante con la familia no es lo mismo que una salida personal.

La diferencia debe quedar en el campo `tipo`, `personas` y `notas`.

### Regla 4 — La IA puede inferir, pero debe indicarlo

Si la IA completa campos por inferencia, debe indicarlo con `*inferido*` para que Jesé pueda corregir.

### Regla 5 — Registrar aunque sea incompleto

Es mejor un registro incompleto que ningún registro.

La IA puede enriquecer el registro más adelante si aparece más contexto.

## Resumen mensual

Al final de cada archivo mensual, después de todas las transacciones, se incluye un resumen:

```markdown
---

## Resumen del mes

| Indicador              | Valor       |
|------------------------|-------------|
| Total ingresos         | ₡X,XXX,XXX  |
| Total gastos           | ₡X,XXX,XXX  |
| Flujo neto             | ₡X,XXX,XXX  |
| Categoría mayor gasto  | —           |
| Gastos extraordinarios | X           |
| Gastos recurrentes     | X           |

### Observaciones del mes

[Notas narrativas sobre patrones, decisiones importantes, aprendizajes.]
```

## Cómo registrar desde el chat

Jesé puede enviar:

- Texto: `"Gasté ₡15,000 en farmacia para mamá"`
- Foto de ticket o factura
- Alerta bancaria o notificación de pago
- Nota de voz transcrita
- Lista al final del día

La IA se encarga de:

1. Interpretar el evento.
2. Clasificarlo usando este RFC.
3. Preguntar solo si falta información crítica.
4. Proponer el bloque de registro.
5. Actualizar el archivo del mes correspondiente.
